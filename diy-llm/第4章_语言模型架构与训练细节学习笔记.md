# 第 4 章：语言模型架构与训练细节学习笔记

这一章先回顾原始 Transformer，再介绍现代大模型对归一化、前馈网络、位置编码和注意力机制做出的改进。学习时不用一次记住全部变体，先弄清每个组件解决什么问题。

## 4.1 标准 Transformer 架构

Transformer 的核心是自注意力。它不需要像 RNN 一样按顺序逐个处理 token，因此更适合并行计算，也能直接建立相隔很远的 token 之间的联系。

一个 Transformer Block 可以先看成：

```text
输入
→ 自注意力
→ 残差连接与归一化
→ 前馈网络
→ 残差连接与归一化
→ 输出
```

### 4.1.1 位置编码

自注意力本身只看到一组向量，并不知道词语顺序。如果没有位置信息，“我爱你”和“你爱我”就很难区分。

原始 Transformer 使用固定的正弦、余弦位置编码，把位置向量直接加到词向量上。不同维度使用不同频率，使模型既能感知相邻位置，也能表示更远的距离。

### 4.1.2 多头自注意力

输入会分别经过三个线性变换得到 Q、K、V：

- Q（Query）：当前 token 想找什么信息；
- K（Key）：每个 token 提供什么索引；
- V（Value）：真正要汇总的内容。

核心计算可以写成：

```text
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V
```

先用 `QKᵀ` 算相关性，再经过 softmax 得到权重，最后按权重汇总 V。

除以 `√dₖ` 是为了防止维度增大后点积数值过大，使 softmax 过于极端、梯度变小。

多头注意力会把隐藏维度拆成多个头。不同头可以学习不同的关联方式，最后再把各头结果拼接起来。

**Tip:** “某个头负责语法、另一个头负责指代”只是帮助理解的比喻，实际模型中的注意力头通常没有这么明确、固定的分工。

对于生成式模型，还要加入因果掩码，让当前位置只能看到自己和前面的 token，不能提前看到后面的答案。

### 4.1.3 LayerNorm 与残差连接

残差连接把输入直接加回子层输出：

```text
y = x + SubLayer(x)
```

这相当于给信息和梯度提供一条直接通路。即使某一层暂时没有学好，也可以先保留原输入。

LayerNorm 会对单个样本的隐藏维度做归一化，让数值范围更加稳定。原始 Transformer 使用 Post-Norm：

```text
子层 → 残差相加 → LayerNorm
```

### 4.1.4 前馈网络与激活函数

注意力负责不同 token 之间交换信息，前馈网络则对每个 token 的特征做进一步变换。原始结构是：

```text
d_model → 更宽的隐藏层 → ReLU → d_model
```

如果没有非线性激活函数，多层线性变换合起来仍然只是一次线性变换，网络无法表达复杂关系。

## 4.2 Transformer 的现代变体

现代大模型仍然以 Transformer Block 为基础，变化主要集中在归一化、FFN、激活函数、位置编码和注意力方式。

### 4.2.1 归一化

现代模型常用 Pre-Norm：

```text
LayerNorm → 子层 → 残差相加
```

它让残差路径更加直接，深层模型通常更容易稳定训练。部分模型还会在子层前后都放归一化，以进一步减少梯度尖峰。

另一个常见变化是 RMSNorm。它不再减去均值，主要根据均方根缩放输入。与 LayerNorm 相比，RMSNorm 计算和数据搬运更少，所以在许多现代语言模型中更常见。

**Tip:** Pre-Norm、Post-Norm 和双重归一化不是简单的“新的一定更好”。它们还会和模型深度、初始化、学习率等设置共同影响训练稳定性。

### 4.2.2 前馈网络

原始 FFN 是两个线性层加一个激活函数。现代模型常去掉线性层中的 bias，并使用门控结构。

门控结构可以理解成有两条支路：一条提供内容，另一条产生“开关”，两者逐元素相乘后再投影回模型维度。

```text
内容支路 × 门控支路 → 输出投影
```

### 4.2.3 激活函数

- ReLU：简单快速，小于 0 的部分直接变成 0。
- GELU：变化更加平滑，早期 GPT 等模型常用。
- SwiGLU / GeGLU：把激活函数与门控结构结合，是现代模型常见设计。

门控结构增加了一些计算，但通常能提高模型的表达能力。

### 4.2.4 位置编码与 RoPE

RoPE 不把位置向量直接加到输入上，而是在注意力计算中旋转 Q 和 K。两个位置的旋转角度相减后，自然留下相对距离信息。

理解 RoPE 时先记住三点：

- 它作用在 Q、K 上；
- 它更关注 token 之间的相对位置；
- 它没有额外需要学习的位置参数。

高维向量会被两两分组，每两个维度看成一个二维平面，然后根据 token 位置进行旋转。课程还介绍了只旋转部分维度等轻量变体，它们的共同目标是平衡位置信息、语义表示和长上下文能力。

### 4.2.5 注意力机制的变体

标准多头注意力（MHA）中，每个头都有自己的 Q、K、V。生成文本时，历史 K、V 会保存在 KV Cache 中，避免每生成一个新 token 都重新计算全部历史内容。

| 方式 | K、V 的使用方式 | 主要特点 |
|---|---|---|
| MHA | 每个头各自一组 K、V | 表达能力强，KV Cache 较大 |
| MQA | 所有查询头共享一组 K、V | 最省缓存，但共享较多 |
| GQA | 若干查询头共享一组 K、V | 在效果和推理效率之间折中 |

滑动窗口注意力只关注附近的一段 token，可以降低长文本的计算量。稀疏注意力则会先筛选重要位置，再对少量位置进行完整计算。

课程后面介绍的 DSA、CSA、HCA 都可以先按这个思路理解：**减少需要参与完整注意力计算的历史信息，同时尽量保留重要的局部细节和全局背景。**

个人扩展：KV Cache 主要是推理阶段的问题。训练时通常可以并行处理整段序列；自回归生成必须一次产生一个 token，历史 K、V 的读取量就会逐渐成为显存和速度瓶颈。

## 4.3 超参数考量与设计原则

常见架构超参数包括：

- `d_model`：每个 token 的隐藏维度；
- `num_layers`：Transformer Block 数量；
- `num_heads`：注意力头数；
- `head_dim`：每个注意力头的维度；
- `d_ff`：前馈网络中间维度；
- `vocab_size`：词表大小；
- `context_length`：上下文长度。

通常有：

```text
d_model = num_heads × head_dim
```

原始 ReLU FFN 常把 `d_ff` 设为 `d_model` 的约 4 倍；使用 GLU 后因为多了一条门控支路，常采用约 `8/3 × d_model` 的中间维度，使参数量保持在相近范围。

这些比例只是经验起点，不是固定答案。模型做深还是做宽，也要考虑训练数据、硬件矩阵尺寸、通信开销和最终部署需求。

**Tip:** 对初学者来说，优先复用成熟模型的配置，再做小规模消融实验，比凭感觉同时修改层数、宽度和头数更可靠。

## 4.4 模型稳定性

大模型训练时间很长，偶尔一次梯度爆炸就可能破坏后续训练。除了观察 loss，还要关注梯度范数、logits 范围以及是否出现 `nan`、`inf`。

课程重点提到 softmax 的稳定性。softmax 含有指数和除法，输入过大时容易让概率分布过于极端。

### 4.4.1 z-loss

输出层 softmax 前会产生 logits。z-loss 对 softmax 的归一化量增加一个较小的约束，防止 logits 整体不断变大，从而让训练更稳定。

它一般作为原任务损失之外的辅助项，而不是替代交叉熵损失。

### 4.4.2 QK-Norm

另一种做法是在计算 `QKᵀ` 之前先对 Q、K 做归一化，直接控制注意力 logits 的数值范围，避免注意力 softmax 进入不稳定区域。

```text
Q、K 归一化 → QKᵀ / √dₖ → softmax
```

个人扩展：稳定性技巧不是越多越好。出现问题时应先保存日志和检查点，判断是数据异常、学习率过大、精度溢出还是模型结构问题，再决定增加梯度裁剪、QK-Norm 或其他约束。

## 个人扩展：一个完整的数据流

把本章组件连起来，一次 decoder-only 语言模型前向传播可以简化成：

```text
token ID
→ token embedding
→ 加入或应用位置信息
→ 多层 Transformer Block
   ├─ 归一化
   ├─ 因果自注意力
   ├─ 残差连接
   ├─ 归一化
   ├─ 门控前馈网络
   └─ 残差连接
→ 输出层
→ 每个位置的词表 logits
→ 预测下一个 token
```

后面阅读 LLaMA、Qwen 等模型源码时，名称可能不同，但大体都能沿着这条数据流找到对应组件。
